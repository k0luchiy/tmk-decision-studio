# Frontend (`frontend/`)

React + Vite (SPA) кокпит: экран решения, графики, формула-дерево.

Правило: фронт импортирует **только `@app/contract`**, вызывает `/api` и **не считает сам**.
Вся логика расчёта и работа с данными живут в `shared/` и вызываются из `backend/`;
фронт не импортирует `@app/core` и `@app/data` напрямую.

Каталог пока пуст (заготовка). Реальный проект добавляет второй разработчик.
