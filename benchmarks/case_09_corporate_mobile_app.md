# Контрольный кейс №9: Корпоративное мобильное приложение металлурга (iOS / Android / 1C:ЗУП)

* **Категория:** Пользовательские корпоративные сервисы / Mobile Dev & HR-Tech (Mid-High Budget)
* **Целевой контур:** Дирекция по персоналу (HR) / Внутренние коммуникации / 1С:ЗУП КОРП
* **Отраслевой контекст:** Предприятия ТМК (десятки тысяч производственных рабочих). Отсутствие стационарных ПК у станочников, вальцовщиков и операторов печей. Необходимость оперативного доведения графиков смен («день-ночь-48»), выдачи электронных расчетных листков по 136 ТК РФ, учета норм выдачи спецодежды (СИЗ) и вовлечения рабочих в программу непрерывных улучшений (Бережливое производство).

---

## 1. Постановка задачи и контрольные промпты

### Вариант 1 (Технический / Инженерный бриф):
> «Разработка защищенного кроссплатформенного мобильного приложения (Flutter / Dart) для сотрудников промышленного холдинга под платформы Android (с публикацией в RuStore) и iOS. Ключевой функционал: авторизация по корпоративному SSO и номеру табельного билета с двухфакторной аутентификацией (SMS/Telegram-код); модуль "Мой доход" с защищенным просмотром детализации расчетных листков из 1С:ЗУП; персональный календарь сменности и переработок; модуль КЭДО (кадровый электронный документооборот — заказ справок 2-НДФЛ, согласование отпусков); модуль учета спецодежды (размеры, сроки замены касок/ботинок по нормам); сервис "Фабрика идей" для отправки рацпредложений по оптимизации цеха с фотофиксацией. Архитектура: Backend-for-Frontend (FastAPI / PostgreSQL), шифрование локальных данных (SQLCipher), полное соответствие требованиям ФЗ-152 "О персональных данных".»

### Вариант 2 (Пользовательский / Неформальный бриф):
> «Нужно удобное мобильное приложение для заводчан на телефон, чтобы каждый рабочий мог в любой момент посмотреть свой расчетный листок с зарплатой, сменный график, узнать, когда положена новая спецодежда по размеру, и отправить с телефона фото с идеей, как улучшить работу в цехе. Чтобы приложение легко скачивалось из RuStore и данные по зарплате были надежно защищены от взлома.»

## 4. Сравнительный расчет себестоимости: In-House vs Подрядчик

### Вариант Б: Привлечение внешнего подрядчика (Mobile Agency)
* Оценка подрядчика (с буфером на согласование с корпоративной службой безопасности +25%): $900 \times 1.25 = 1\,125 \text{ часов}$.
* **Ценовая вилка подрядчика:**
  * *Нижняя граница (сильная региональная мобильная студия, 4 200 руб./час):*
    $$1\,125 \times 4\,200 = 4\,725\,000 \text{ руб.} \times 1.2 \text{ (НДС)} = 5\,670\,000 \text{ руб.}$$

    $$1\,125 \times 5\,400 = 6\,075\,000 \text{ руб.} \times 1.2 \text{ (НДС)} = 7\,290\,000 \text{ руб.}$$
* **Диапазон стоимости подрядчика:** **5 500 000 – 7 500 000 руб.**
* **Срок выполнения подрядчиком:** **2.5 – 3.5 месяца** (за счет отлаженного конвейера мобильного дизайна и готовых UI-компонентов).
