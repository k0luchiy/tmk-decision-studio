# Приложения (`apps/`)

Здесь живут два приложения поверх ядра и пакетов:

| Приложение | Стек | Ответственность |
|---|---|---|
| `web/` | React + Vite (SPA) | Кокпит: экран решения, графики, формула-дерево. Добавляет второй разработчик. |
| `api/` | Fastify | Backend-for-frontend: intake, расчёт через `@app/core`, экспорт, выдача контракта фронту. |

Правило: **фронт импортирует только `@app/contract` и считает backend**. Вся
логика расчёта и работа с данными остаются в `packages/` и вызываются из `api/`;
фронт не импортирует `@app/core` и `@app/data` напрямую.

Каталоги `web/` и `api/` пока пусты (заготовки). Реальные проекты добавляются
вторым разработчиком (фронт) и backend-разработчиком (API).
