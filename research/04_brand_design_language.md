# 04 — Бренд и визуальный язык ТМК / ТМК++ (первоисточники)

**Составлено:** 2026-11-08, методом прямого скрапинга `tmkplusplus.tmk-group.ru` (обход JS-cap: cookie `CAP=checked`) и `www.tmk-group.ru` / `.com`, плюс официальный брендбук ТМК (редакция 2021).
**Назначение:** дизайн-токены, типографика, тон и готовые ассеты для интерфейса оценки ИТ-работ, стилизованного под заказчика.

---

## 1. Знак (логотип) — проверено по вектору с сайта

**Геометрия знака** (viewBox `0 0 70 70`), подтверждена рендером сохранённого SVG:

- тонкая прямоугольная рамка-квадрат (в 2px-контуре);
- внутри — **жирные прописные «ТМК»** ступенькой по диагонали сверху-вниз-вправо, шрифт без засечек, широкий;
- над/справа от букв — **сегмент окружности (свищ-арка)**, утолщённый к середине и сходящий на нет к концам, идущий из левого-верхнего угла к правому-нижнему, **параллельно** ступеньке букв.

Брендбук формулирует это так: «чёрный квадрат с оранжевым сегментом круга из левого верхнего в правый нижний угол, надпись "ТМК" параллельно сегменту». Смысловые слои знака (по брендбуку): квадрат = **печь/доменная труба**, оранжевый сегмент = **пламя/огонь**, вся композиция читается как срез трубы.

Знак ТМК++ — тот же, с двумя «плюсами» после ТМК (вектор `tmkpp_wordmark.svg`, viewBox `778×691`). На сайте контур белый с оранжевым hover-состоянием (класс `.svg2orange`).

⚠️ **Важный вывод:** голубой `#3490DC` на сайте ТМК++ — мусор от шаблона, не корпоративный цвет. В своём интерфейсе его использовать нельзя, иначе «стиль заказчика» будет подделкой. Брендовое ядро строгое: **чёрный/графит + оранжевый #EC6608 + тёплый серый**, без градиентов.

Дополнительный производный оранжевый, встречающийся в векторе ТМК++: `#D88549` (приглушённая терракота) — допустим как вторичный тон.

### 2.3 Рекомендуемые дизайн-токены для инструмента (в духе заказчика)

```
/* Поверхности и текст — индустриальный графит */
--bg-app:        #0E1013   /* тёмная тема: почти-чёрный, тёплый графит */
--bg-panel:     #161A1E
--bg-subtle:    #1D2227
--border:       #2A3036   /* тонкие 1px-границы вместо теней */
--text-primary: #F2F4F6
--text-secondary:#9AA3AB
--text-muted:   #6B7480

/* Тема «документ/отчёт» для PDF-выгрузки — белый фон, тот же оранжевый */
--paper-bg:     #F7F6F3
--paper-text:   #221C1C

--accent:       #EC6608   /* TMK Orange — только CTA, выделение, вердикт */
--accent-hover: #F57A20
--accent-soft:  rgba(236,102,8,0.12)   /* фон активного состояния, НЕ заливка карточек */

/* Семантика (не бренд): confidence/RAG */
--good:         #2FA36B
--warn:         #D9A13B
--risk:         #D9573B

/* Категориальные (цвето-безопасные, Okabe-Ito): внутренняя команда vs подрядчик */
--series-inhouse: #0072B2   /* синий */
--series-vendor:  #E69F00   /* оранжево-жёлтый — не совпадает с #EC6608 accidental, проверить различимость */
```

Правило: **оранжевый #EC6608 используется не чаще, чем на 5-10% площади** — CTA, активное состояние, вердикт. Если оранжевый одновременно категориальный цвет ряда данных, различимость с `#E69F00` надо проверять — поэтому в паре «инсорсинг/подрядчик» лучше `#0072B2` (синий) vs `#CC79A7` (розово-лиловый) или `#009E73` (зелёный), а оранжевый оставить интерфейсу.

## 3. Типографика

| Слой | Шрифт | Статус |
|---|---|---|
| **Брендбук ТМК** | **Europe / EuropeCond / EuropeDemi / EuropeExt** | канонический корпоративный шрифт (в т.ч. EuropeCond для плотных заголовков) |
| **Веб-свойства ТМК/ТМК++** | **PF Din Text Comp Pro** (weights 100 XThin → 800 XBlack) | фактически используется на tmkplusplus и tmk-group; это DIN-семейство, индустриально-технический характер, близок EuropeCond |
| **Системный fallback сайта** | Roboto, sans-serif | `--font-family-sans-serif` в app.css |

**Для инструмента:** заголовки и вердикт-числа — condensed DIN-подобный (локально уже есть `PFDinTextCompPro-*.woff` в `assets/brand/fonts/`; web-free аналог — **Barlow Condensed / Archivo Narrow / Oswald**). Текст UI и таблицы — **Inter**. Цифры в таблицах и формулы — **IBM Plex Mono / JetBrains Mono** с `font-variant-numeric: tabular-nums`.

> ⚠️ Лицензионная оговорка: PF DIN Text Comp Pro — коммерческий шрифт ParaType. Файлы в `assets/brand/fonts/` сохранены **только как референс для подбора свободного аналога** — Barlow Condensed, Archivo Narrow, Oswald или D-DIN (свободно распространяемое DIN-семейство, наиболее близкое по характеру). В публичный продукт шрифты ТМК не встраивать.

## 4. Артикуляция и тон

Сайты ТМК++ построены на: графитовом + белом, оранжевых акцентах, **контурных линовых иконках** (stroke-иконки 1-1.5px в currentColor), тонких горизонтальных разделителях, лаконичных безглагольных заголовках, без плоских заливок и градиентов. Тексты короткие, перечислевые, технически точные («Единая омниканальная точка входа», «Формализованный каталог услуг с определенными SLA»). В интерфейсе оценочного инструмента уместен тот же регистр: плотные таблицы, штриховые иконки, минимум декора, оранжевый как единственный цветной сигнал.

## 5. Информационная архитектура веб-свойств (что о ней надо знать)

Навигация ТМК++: О ТМК++ (История, Компетенции, Менеджмент) · Компетенции (Разработка, Поддержка, ИТ-консалтинг, Администрирование, Обслуживание и ремонт, Информационная безопасность) · Работа в ТМК++ (Обучение и развитие, Управление карьерой, Корпоративная жизнь, Социальный пакет, Вакансии) · Контакты.

**Наблюдение, важное для нашего продукта:** у ИТ-кластера **нет публичного раздела «кейсы/проекты/новости»** — сайт является HR-брендовым. Все реальные цифры проектов (человеко-часы, эффекты) публикуются в пресс-релизах ТМК и в СМИ. Это подтверждает дефицит, который наш инструмент закрывает: **у заказчика нет публичного, воспроизводимого способа показать, сколько стоит ИТ-работа и почему**.

Техстек сайтов: **Laravel + jQuery + slick-carousel + Font Awesome**, защита входа простым JS-cap (cookie `CAP=checked`), DDoS-Guard на основном домене. Вывод для нас: консервативная, локально-хостируемая инфраструктура; интерфейс должен работать **без внешних CDN и без тяжёлых SPA-зависимостей**, в идеале — self-hosted шрифты и ассеты.

## 7. Как это транслируется в наш интерфейс (кратко)

1. **Одна акцентная цвета** — #EC6608 — на вердикт и CTA. Всё остальное — графитовая шкала. Ни градиентов, ни «стеклянных» карточек.
2. **Контурная иконка**, 1.25px stroke, currentColor (в tipped в SVG-спрайтах сайта заказчика).
3. **Condensed DIN-заголовки + Inter-текст + моноширинные табличные числа.**
4. **Плотная таблица сметы — главный герой экрана**, не диаграмма. Диаграмм две-три (break-even, tornado, стек TCO), каждая с табличным fallback.
5. **Оранжевая линия-подчёркивание** как единственный повторяющийся мотив (отсылка к арке знака).
6. PDF-выгрузка — «бумажная» версия той же системы: `#F7F6F3`, чёрный текст, оранжевый акцент, PDF-шапка со знаком ТМК++.

Полный спека интерфейса: `research/08_uiux_design_spec.md`.
