# 12 — ТМК: реальные ИТ-закупки (рабочий корпус)

**Дата сбора:** 2026-11-09 · **Источник ядра:** ЭТП ТМК `zakupki.tmk-group.com` · **Файлы:** `data/tmk_it_contracts.csv`, `data/tmk_it_contracts.json`, сырьё — `data/tmk_raw/`

---

## TL;DR

1. **Публичного 44‑ФЗ/223‑ФЗ следа у ТМК нет.** ПАО «ТМК» (ИНН 7710373095) зарегистрировано в реестре организаций 223‑ФЗ (agencyId 671679), но в ЕИС **0 извещений, 0 договоров, 0 планов**. АО «СТЗ», АО «СинТЗ», АО «ТАГМЕТ» — тоже 0. АО «ДИАЙПИ» (ИНН 6625034780) в ЕИС отсутствует. Всё, что есть, живёт на собственной ЭТП.
2. **ЭТП ТМК отдаёт данные без логина через Ext.Direct API.** Гостевая сессия + `Procedure.list` = **300 967 процедур** в реестре. Собрано **5 724** уникальные процедуры по 35 ИТ‑запросам.
3. **Корпус: 60 записей**, 2019–2026, сумма НМЦК **1,82 млрд ₽**, медиана **18,58 млн ₽**, Q1–Q3 = **7,86–36,54 млн ₽**, максимум **281,66 млн ₽**.
4. **Цена в CSV = НМЦК первого лота** (не цена победы). Победная цена есть в `scope_notes` у 52/60 записей, поставщик — у 51/60. НДС ЭТП не расщепляет — колонка `vat_incl` честно помечена `unspecified`, кроме одной строки с проверенной ставкой 18%.
5. **Главный вывод для «market analogues»:** у ТМК устойчивые годовые бюджеты на ИТ‑сервисы — SAP‑инфраструктура ≈ **1,6–2,6 млн ₽/мес**, SOC ≈ **3 млн ₽/мес**, SIEM ≈ **38–44 млн ₽/год**, 1С‑ERP внедрения — **30–282 млн ₽** за программу.

## 2. Методология и доступ

### 2.1 ЭТП ТМК — основной источник (доступ получен)

Площадка — ExtJS SPA. Публичный API:

```
GET  /api.php                                   → список Ext.Direct-модулей
POST /index.php?rpctype=direct&module=default
     {"action":"Index","method":"index","data":[],"type":"rpc","tid":1}
     → гостевая сессия, auth_token, конфиг, словари

POST /index.php?rpctype=direct&module=default
     {"action":"Procedure","method":"list",
      "data":[{"start":0,"limit":25,"query":"SAP",
               "sort":"date_published","dir":"DESC"}], ...}
     → {"totalCount": 300967, "procedures":[...]}

POST .../module=tmk  {"action":"Company","method":"contragentList","data":[{"start":0,"limit":50}]}
     → 57 726 контрагентов (id → name/short_name)
```

Работающие фильтры `Procedure.list`: `query` (полнотекст, подстрочный), `organizer_contragent_id`, `procedure_type`, `registry_number`, `date_published_from`. Не работают: `subject`, `title` (точное совпадение), `searchString`, `okpd2`.

Ограничения API, которые пришлось обойти:
- **25 записей на страницу**, `limit` игнорируется → пагинация по `start`.
- Поля цены и победителя приходят **только в списке**, а `Procedure.view{procedure_id}` даёт шапку/лоты без победителя; `Lot.load{lot_id}` даёт `nds_rate`, `date_*`, юниты, но не имя победителя.
- Имя победителя восстанавливается **только** через `contragentList` по `winner_id`.

Ход сбора: 35 запросов (`программное обеспечение`, `1С`, `SAP`, `MES`, `BI`, `лицензи`, `сопровождение`, `техническая поддержка`, `информационн`, `АСУ`, `SCADA`, `кибербезопас`, `Oracle`, `Microsoft`, `ERP`, `портал`, `база данных`, `интеграц`, `мониторинг`, …), дедуп по `id`, затем фильтр по заказчику (в `short_name` есть «ТМК») и по заголовку.

**Блокировка.** После ~1 300 запросов (harvest + дамп контрагентов) хост начал рвать TLS‑хендшейк: TCP‑коннект проходит, HTTPS — таймаут. Дамп контрагентов успел закрыть **50 950 из 57 726 (88%)** — этого хватило, чтобы резолвить всех 53 победителей с непустым `winner_id`. Enrichment через `Lot.load` для всех 60 строк завершить не удалось; там, где он был выполнен до блокировки, зафиксировано `nds_rate = 18`.

### 2.2 ЕИС `zakupki.gov.ru` — проверено, пусто

Проверялись реестры 223‑ФЗ (извещения, договоры, планы) по токену заказчика:
- ПАО «ТМК», ИНН 7710373095, КПП 770901001, ОГРН 1027739217758, agencyId 671679 → **0 / 0 / 0**;
- АО «Северский трубный завод», ИНН 6626002291 → **0 / 0 / 0**;
- АО «Синарский трубный завод», ИНН 6612000551 → **0 / 0 / 0**;
- АО «Таганрогский металлургический завод», ИНН 6154011797 → **0 / 0 / 0**;
- АО «ДИАЙПИ», ИНН 6625034780 → организации в ЕИС нет;

Причина: группа частная и закупки по 223‑ФЗ не размещает. Это не «нет данных в выгрузке», это отсутствие самого факта публикации — проверено и по списку, и по карточке организации.

### 2.3 Агрегаторы и зеркала

Подтвердил ключевую запись 2022 г.: «Техническая поддержка, удалённый мониторинг и администрирование инфраструктуры КИС SAP ПАО «ТМК»», итог **94 166 666,67 ₽**, два лота: 1 год — **31 666 666,67 ₽**, 3 года — **62 500 000,00 ₽**. Имя победителя и даты у агрегатора закрыты логином.

### 2.4 Чего получить не удалось

- Имя победителя для 9 процедур (победитель не опубликован / стадия не завершена).
- `nds_rate` и ОКПД2 по всем 60 строкам (блокировка ЭТП).
- Договорный реестр АО «ДИАЙПИ» как поставщика — в ЕИС его нет, на ЭТП видны только закупки заказчиков.
- ТЗ/документация лотов (PDF) — требуют авторизованного скачивания.

## 6. Ограничения покрытия (читать до использования цифр)

1. **Это не случайная выборка.** Отобраны ИТ‑закупки с ценой; крупные контракты доминируют. Медиана 18,6 млн ₽ — медиана *отобранных ИТ‑закупок ТМК*, а не всех закупок группы.
2. **Цена = НМЦК первого лота, не цена победы.** Победная цена есть у 52/60 и лежит в `scope_notes` (`winning_bid=`). Для 7 мультилотовых процедур в `scope_notes` указан `procedure_total`.
3. **НДС не расщеплён источником.** ЭТП отдаёт одну сумму; проверенная ставка — 18%. В CSV `vat_incl = unspecified` (кроме одной строки). Нельзя молча считать цены «без НДС».
4. **ОКПД2 выведен.** ЭТП его не публикует; в лотах есть только внутренний `category_code`. Коды 62.01/62.02/62.09/26.20 — наша реконструкция по предмету, не поле источника.
5. **Срок договора почти не публикуется.** Заявленный срок есть у 3/60; у остальных в `scope_notes` лежит `tender_window_months` — это окно процедуры, а не срок контракта. Для rate card использованы только записи с явным сроком либо с явной годовой природой (bicotender).
6. **ЭТП заблокировала IP после ~1 300 запросов.** Часть enrichment (`nds_rate`, ОКПД2, ТЗ) не выполнена. Данные списка (цена, даты, лоты, победитель) получены полностью.
7. **ЕИС пуст по ТМК.** 44‑ФЗ/223‑ФЗ данные для этой группы не существуют в природе, а не «не нашлись».
8. **ДИАЙПИ как поставщик не виден.** Внутренние трансферты ТМК → ДИАЙПИ по открытым источникам не восстанавливаются; это остаётся главным белым пятном для оценки внутренней себестоимости.

## 7. Воспроизводимость

```
data/tmk_it_contracts.csv     # 60 строк, финальный корпус

data/tmk_raw/raw_procedures.jsonl   # 5 724 процедуры ЭТП (сырьё)

data/tmk_raw/build.py               # сборка CSV/JSON
```
