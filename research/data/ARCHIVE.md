# Архив исходных данных

Это архив исходных материалов; рабочие датасеты вынесены в `data/datasets/`,
оригиналы сохранены для провенанса.

Код во время запуска читает только `data/`, а не `research/`. Не удаляйте и не
перемещайте файлы из этого каталога: на них ссылается провенанс манифеста
(`source` в `data/manifest.json`).
