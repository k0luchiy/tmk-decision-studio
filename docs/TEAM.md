# Роли и вклад

> Имена участников добавьте перед защитой. Роли ниже описывают зоны
> ответственности и артефакты, которые каждый должен уметь объяснить.

| Роль | Зона | Артефакты |
|---|---|---|
| Капитан / продукт | рамка решения, вердикт, защита | `docs/01_vision.md`, `PRESENTATION.md` |
| Ядро расчёта | WBS, FP-lite, аналоги, сценарии | `shared/core/`, `METHOD.md` |
| Данные | контракт, датасеты, HelpDesk, Data Hub | `shared/data/`, `DATA_HUB.md` |
| Backend | Fastify API, экспорт, Jev | `backend/`, `10_api_contract.md` |
| Frontend | кокпит, графики, формула-дерево | `frontend/`, скриншоты |
| QA / воспроизводимость | тесты, Docker, CI, benchmark | `scripts/`, `docker-compose.yml`, отчёты |

## Правило объяснимости

Каждый участник должен уметь показать:

1. откуда берётся его число/экран;
2. какой файл или формула это реализует;
3. что произойдёт при ошибке/пустом вводе;
4. какое ограничение остаётся.
