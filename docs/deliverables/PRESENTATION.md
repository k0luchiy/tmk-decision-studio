# Презентация и демо

## 6 слайдов

1. **Проблема.** «Сделать или заказать» решают на глаз; нужна разложимая оценка.
2. **Решение.** TMK Decision Studio: бриф → три сценария → вердикт → PDF.
   Скриншот: `docs/screenshots/02-overview.png`.
3. **Внутренняя оценка.** WBS по ролям, O/M/P, fully loaded, найм, bench, TCO.
   Скриншот: `docs/screenshots/03-parameters.png`.
4. **Рыночная оценка.** 49 опубликованных аналогов + 60 контрактов ТМК,
   нормализация, медиана, P10–P90. Скриншот: `docs/screenshots/05-justification.png`.
5. **Данные и поддержка.** HelpDesk-импорт, Data Hub, версии датасетов.
   Скриншот: `docs/screenshots/06-data.png`.
6. **Ограничения и следующий шаг.** Benchmark, калибровка, пилот на закрытых
   проектах. Честно: оценка порядка, не смета.

## Живое демо (5 минут)

1. Открыть старт: `docs/screenshots/01-start.png`.
2. Выбрать D1 → «Обзор».
3. Показать P10–P90, три сценария, confidence, календарные допущения.
4. Открыть «Обоснование»: аналоги, риски, допущения, формула-дерево.
5. Открыть «Данные»: Data Hub, очередь ревью, версия `2026.11.x`.
6. Экспортировать PDF и показать матрицу трёх сценариев.

- **Что если Jev недоступен?** `cache`/`rules`, расчёт продолжает работать.
