## 4. Приоритеты и cut-line

Правило из регламента: инженерия (30) и две оценки (30) неприкосновенны. UX (5) и защита (5) урезаются первыми.

**Если отстаём к 16:00 10.11 — отрезаем сверху вниз:**

1. P2 всё (NPV, темы, горячие клавиши, калибровка MAPE на 4 строках).
2. XLSX (оставляем JSON-снимок).
3. Режим «Target» (обратный расчёт).
4. Матрица решений (оставляем текстовый вердикт и break-even).
5. Live-вызовы Jev (оставляем кэш и правила; это уже заложено).
6. Третий сценарий «пик» (оставляем команда vs подрядчик vs гибрид).

**Не режем никогда:** расчёт двух сценариев на одной декомпозиции, диапазон Мин/Средн./Макс, аналоги ≥ 3 с источниками, допущения и риски, формула по клику, PDF, тесты ядра, `DECISIONS.md`, README с запуском.
