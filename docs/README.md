## Одной фразой

Инструмент принимает описание ИТ-задачи, раскладывает её на одинаковые этапы и считает два сценария — **собственной командой** (fully loaded) и **подрядчиком** (rate card + координация + риск) — с диапазоном сроков и стоимости, аналогами, допущениями, рисками и уровнем уверенности. Любое число раскрывается в формулу с источником.

## Правила ведения

1. Решение, которое меняет проект, записывается в `DECISIONS.md` в день принятия.
2. Цифры в документах — только с источником (`research/...` или `data/...`) или с пометкой **[допущение]**.
3. Документы обновляются вместе с кодом: если код расходится с документом, правим документ или код в этот же коммит.
