# Скриншоты

Сняты в Chromium 1440×1000 с работающим API и демо-кейсом D1.

| Файл | Экран | Для чего |
|---|---|---|
| `01-start.png` | старт | обложка демо |
| `02-overview.png` | обзор / вердикт | главный слайд |
| `02b-overview-calendar.png` | календарные допущения | объяснимость срока |
| `03-parameters.png` | параметры | intake и сценарии |
| `04-analytics.png` | аналитика | графики и распределение |
| `05-justification.png` | обоснование | аналоги, допущения, риски |
| `06-data.png` | данные | Data Hub и версии |

Пересобрать:

```bash
npm run dev
# затем открыть приложение и сделать скриншоты, либо использовать Playwright
```
