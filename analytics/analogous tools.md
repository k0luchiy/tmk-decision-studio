инструменты-аналоги
Quanter — коммерческое веб-приложение для оценки стоимости ПО на основе функциональных точек (ISO/IEC 14143) и базы LedaMC. Позволяет сравнивать стоимость с рынком. Это прямой аналог, но с фокусом на подрядчика/рынок.

Dowork — инструмент для оценки проектов в аутсорсинговых бизнесах: сроки, объём, стоимость.

Simple Estimate / Apropo — калькуляторы для агентств и разработчиков, которые быстро генерируют оценки стоимости. Могут служить примером пользовательского сценария «ввод параметров → диапазон стоимости».

ONES / Jira / Azure DevOps — не столько калькуляторы, сколько системы управления проектами с функциями учёта фактических трудозатрат и исторических данных для калибровки оценок. В кейсе они могут быть «источником данных» для вашей модели, а не прямым аналогом интерфейса.

1. Инструменты оценки стоимости разработки и ИТ-услуг
Costlocker -инструмент для агентств и ИТ-компаний, который связывает оценку проектов, планирование ресурсов (реал-тайм учет времени) и маржинальность. Отличный референс для логики «расчета внутренней стоимости» с учетом зарплат, налогов, накладных расходов (overhead) и загрузки специалистов.

Scopevisio / awork - европейские платформы для управления проектами и ресурсного планирования, где встроен мощный модуль предиктивной оценки на базе прошлых проектов. Показывает, как красиво визуализировать отклонения плановых трудозатрат от фактических.

Function Point (FunctionPoint.com)- классический софт для оценки и управления проектами в digital-агентствах. Полезен для понимания того, как структурировать параметры задачи (роли, грейды, ставки).

2. Калькуляторы T&M (Time & Material) vs Fixed Price
Калькуляторы аутстафф- и аутсорс-компаний (например, ERFix, Syncfusion Cost Estimators, калькуляторы крупных интеграторов вроде Крок / Ланит) -многие ИТ-компании имеют внутренние или публичные калькуляторы стоимости разработки ПО.

UX-референс: Пошаговые мастера (Wizards), где пользователь выбирает платформу, стек, сложность интеграций и получает вилку бюджета.
