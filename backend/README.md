# Backend (`backend/`)

Fastify backend-for-frontend (BFF): intake, расчёт и экспорт поверх `shared/`.

Правило: backend использует `@app/{data,core,intake,export}` и выдаёт фронту
контракт. Эндпоинты — см. `docs/10_api_contract.md`.

Каталог пока пуст (заготовка). Реальный проект добавляет backend-разработчик (API).
